# 🏈 《Pocket Commander》— 四分卫养成 × Roguelike 腰旗橄榄球
## Version 1.0 — 核心概念

---

## 一、游戏概述

**一句话描述：** 你是一个天赋异禀但毫无经验的四分卫，在一个由随机生成的联赛赛季中，通过一场场腰旗橄榄球比赛，从街头菜鸟成长为传奇指挥官。

**核心体验：** 每一档进攻都是一次"微型roguelike决策"——阅读防守、选择战术、执行传球——失败了就学到东西，成功了就变得更强。

**类型融合：**
- 🎮 Roguelike：每个赛季随机生成对手、天气、场地条件、事件；死亡（赛季淘汰）后保留部分永久成长
- 🌱 养成：四分卫属性成长、技能树解锁、球队招募与培养
- 🧠 策略：真实的腰旗橄榄球战术系统，简化但不失深度
- ⚡ 动作：传球时机、跑位判断的实时操作（简化的操作手感）

## 二、Game Loop 设计

### 2.1 单档进攻 Loop（30秒-1分钟）— 核心玩法循环

```
┌─────────────────────────────────────────────────┐
│  1. 读防守阵型（2-3秒观察期）                      │
│     ↓                                            │
│  2. 选择/修改进攻战术（从手牌中选）                  │
│     ↓                                            │
│  3. Snap! 实时执行阶段                             │
│     - 观察接球手跑位路线展开                        │
│     - 判断防守人覆盖情况                            │
│     - 选择传球目标 + 按住蓄力决定传球力度             │
│     - 或选择自己持球跑（QB Rush）                    │
│     ↓                                            │
│  4. 结算：码数/达阵/抄截/不完整传球                  │
│     ↓                                            │
│  5. 获得经验 + 战术洞察碎片                         │
└─────────────────────────────────────────────────┘
```

### 2.2 单次Drive Loop（3-8分钟）— 一次进攻组驱动

```
从己方某码线开始 → 重复单档Loop →
结果：达阵(TD) / 任意球(FG) / 丢球权(Turnover) / 时间耗尽

每次Drive结束获得：
- 比赛货币（Playbook Points）
- 球员疲劳值变化
- 动态难度调整
```

### 2.3 单场比赛 Loop（15-25分钟）— Roguelike 单次 Run

```
赛前：
  → 侦察对手（有限信息，花资源可获得更多情报）
  → 选择首发阵容（5人制腰旗）
  → 选择携带的战术牌组（Playbook Deck，最多带15张）

比赛中：
  → 交替进攻/防守（防守时做简化的play-call决策）
  → 中场事件（随机buff/debuff，受伤，天气变化）
  → 关键时刻系统（Clutch Moments）

赛后：
  → MVP评选 → 属性成长
  → 商店/选秀：选择新战术卡、装备、队友
  → 随机事件（媒体采访选项影响士气/声望）
```

### 2.4 赛季 Loop（3-5小时）— 单次 Roguelike Run

```
赛季结构（8场常规赛 + 最多3场季后赛 = 最多11场比赛）：

第1-3场：新手村，学习基础阵型和战术
第4-6场：难度跃升，出现复杂防守
第7-8场：争夺季后赛席位，对手有特殊能力
季后赛：精英级对手，需要完整战术理解

赛季失败（未进季后赛/季后赛淘汰）：
  → 保留：永久技能点、解锁的战术知识、成就
  → 失去：当赛季的球队阵容、临时装备、赛季特殊卡牌

赛季胜利（夺冠）：
  → 解锁新难度层级
  → 永久解锁传奇战术卡
  → 进入下一"纪元"（Meta-progression）
```

### 2.5 Meta Loop（20小时+）— 永久进度

```
纪元系统（共5个纪元）：
  纪元1：街头腰旗（5v5，基础规则）
  纪元2：校园联赛（加入更多战术元素）
  纪元3：城市联盟（天气/场地系统全开）
  纪元4：全国锦标赛（对手AI完整版）
  纪元5：传奇殿堂（无限难度攀升）

每个纪元 = 至少通关一个赛季
每个纪元解锁新的：
  - 战术类型
  - 球员种类
  - 场地类型
  - Boss级对手
```

## 三、战术系统（核心教学设计）

### 3.1 进攻战术卡牌系统

战术以"卡牌"形式呈现，玩家构建自己的 Playbook Deck：

**基础战术类型（纪元1解锁）：**
| 战术名 | 类型 | 路线特点 | 适用场景 |
|--------|------|----------|----------|
| Slant | 短传 | 斜切内线 | 对付Zone防守 |
| Out Route | 短传 | 外切边线 | 对付Man防守 |
| Go/Fly | 长传 | 直线冲刺 | 对付单人盯防 |
| Curl | 中传 | 跑出转身 | 安全选择 |
| Screen Pass | 特殊 | 短传给前方 | 对付Blitz |
| QB Draw | 跑动 | 四分卫持球跑 | 防守松懈时 |

**进阶战术（纪元2+逐步解锁）：**
- Post Route、Corner Route、Dig/In Route
- Play Action（假跑真传）
- Option Route（接球手根据防守自动变路线）
- Hot Route（临场变阵）
- Mesh Concept、Trips Formation 等

**战术卡牌属性：**
- 稀有度：白/绿/蓝/紫/金（影响路线精度和额外效果）
- 升级：重复获得同卡可升级
- 特殊词缀：「精准」「迅捷」「迷惑」等附加效果

### 3.2 防守阅读系统（教学核心）

**阅读UI设计：**
- Snap前有2-3秒"阅读期"，防守阵型高亮显示
- 视觉提示系统（渐进式）：
  - 纪元1：直接告诉你防守类型（"这是Cover 2"）
  - 纪元2：给你线索（"注意安全卫的站位"）
  - 纪元3：只显示阵型，你自己判断
  - 纪元4+：防守会伪装

**防守阵型教学：**
| 防守类型 | 视觉特征 | 弱点 | 克制 |
|----------|----------|------|------|
| Man-to-Man | 防守人贴身对位 | Go Route / Pick Play | 短传Screen |
| Cover 2 | 两个安全卫深区 | 中路深传 | 边路短传 |
| Cover 3 | 三人分区深防 | Flat区域（边路短） | 中路传球 |
| Cover 4 | 四人深防 | 短传和跑动 | 长传炸弹 |
| Blitz | 多人前冲 | Screen / Hot Route | 无保护长传 |
| Zone Blitz | 混合突袭 | Slant / Quick Out | 需要快速阅读 |

### 3.3 防守回合（简化但有趣）

玩家不直接操控防守球员，而是：
1. 选择防守战术卡（Cover 2/3/Man/Blitz等）
2. 猜测对手进攻意图
3. 观看自动执行结果
4. 猜对 = 大幅增加防守成功率
→ 这让玩家从"进攻者"视角理解防守，形成双向理解

## 四、角色养成系统

### 4.1 四分卫属性

**六大核心属性：**
- 🎯 精准度（Accuracy）：传球准确性
- 💪 臂力（Arm Strength）：传球距离和速度
- 👁 阅读力（Read）：阅读防守的时间和提示
- 🏃 机动性（Mobility）：口袋内移动和QB跑动
- 🧊 冷静（Composure）：压力下的表现衰减
- 🌟 领袖力（Leadership）：队友表现加成

**属性成长方式：**
- 比赛中使用 → 自然成长（用短传多了精准度涨）
- 训练营小游戏（赛季间）
- 装备加成
- 永久天赋树

### 4.2 天赋树（永久进度）

三条天赋路线：
```
         🎯 神射手路线
        /（传球精准、读防强化）
       /
起点 ——— 🏃 双重威胁路线
       \（跑传结合、即兴发挥）
        \
         🧠 战术大师路线
          （战术多样性、队友增强）
```

每条路线约15-20个天赋节点，跨路线有交叉节点。
完全点满一条约需要2-3个完整赛季。

### 4.3 球队管理

**队友系统：**
- 每个赛季开始选择4名队友（5v5腰旗）
- 队友有不同特长：速度型外接手、路线大师、掩护型中锋等
- 队友有羁绊系统：特定组合触发Combo效果
- 赛季中可通过商店替换/升级队友

**队友稀有度与能力：**
- 普通→精英→传奇→神话
- 每个队友独特被动技能
- 升级需要比赛中的默契值积累

## 五、Roguelike 要素

### 5.1 随机生成赛季

每个赛季随机决定：
- 8个对手球队（从敌方池中抽取）
- 每场的天气条件
- 赛季特殊规则（本赛季所有Blitz加强 等）
- 随机事件链

### 5.2 赛季内商店系统

每场比赛后进入商店：
- 购买新战术卡
- 升级现有卡牌
- 购买一次性道具（超时暂停、教练挑战旗等）
- 招募替补球员

货币来源：比赛表现评分 → 转化为Playbook Points

### 5.3 遗物系统（Relic）

赛季中获得的强力被动：
- 「老教练的笔记本」：每场首档自动识别防守
- 「幸运手套」：精准度+15%但臂力-10%
- 「节拍器」：Snap节奏完美时额外+5码
- 共设计50+遗物，分为进攻/防守/通用三类
- 同时最多携带3个遗物

### 5.4 Boss 战

每个纪元的季后赛决赛是Boss战：
- Boss队有独特的AI行为和特殊能力
- 纪元1 Boss：「铁壁教练」— 完美的防守轮换
- 纪元2 Boss：「双面战术家」— 会模仿你最常用的战术来反制你
- 纪元3 Boss：「暴风队长」— 操控天气条件
- 纪元4 Boss：「预言者」— 总是"知道"你的下一手
- 纪元5 Boss：「传奇重现」— 随机使用所有前Boss能力

## 六、教学设计（隐性学习）

### 6.1 核心教学理念

**"你以为在玩游戏，其实在学橄榄球"**

所有教学通过游戏机制自然传递：
- 第一次遇到Cover 2被打爆 → 弹出"教练提示"卡 → 下次遇到时有UI标记
- 反复使用某战术被针对 → 系统提示"对手已经看穿你了" → 迫使玩家学习更多战术
- 防守回合让你站在对面角度思考 → 自然理解攻防博弈

### 6.2 知识图鉴

解锁式的橄榄球知识百科：
- 每学会一个新概念自动解锁对应图鉴页
- 图鉴包含：动画演示、文字解说、实战案例回放
- 图鉴完成度 = 成就进度之一

## 七、内容量估算（24小时+）

| 内容模块 | 预计时长 |
|----------|----------|
| 纪元1（新手学习+首个赛季通关）| 4-5小时 |
| 纪元2（进阶战术+2个赛季） | 4-5小时 |
| 纪元3（完整系统+2个赛季） | 4-5小时 |
| 纪元4（高难度+2个赛季） | 3-4小时 |
| 纪元5（无限攀升模式） | 4小时+ |

| **总计** | **22-27小时+** |

## 八、美术风格方向

- **整体风格：** 美漫风格 × 卡通渲染，类似《Hades》的角色设计感 + 体育漫画的动感
- **色调：** 鲜艳高饱和，每个纪元有主题色（街头=涂鸦风、校园=阳光明亮、城市=霓虹夜景）
- **UI：** 战术板风格的界面，粉笔画质感的路线图
- **角色：** 夸张的体型比例（大头小身），个性鲜明的对手教练设计
- **动画：** 关键时刻（达阵/抄截）有特写演出动画

## V1 自我评审

### 评分：72/100

**优点：**
- ✅ Game Loop层次清晰（档→Drive→比赛→赛季→纪元）
- ✅ Roguelike要素和养成系统结合合理
- ✅ 战术教学通过游戏机制自然融入
- ✅ 内容量充足，超过24小时
- ✅ 防守回合的简化设计让节奏不拖沓

**问题：**
- ❌ 单档进攻的操作手感描述太模糊——"按住蓄力传球"不够有趣，缺乏skill expression
- ❌ 防守回合过于被动，只选战术看动画，可能无聊
- ❌ 缺乏社交/竞技要素，重玩动力可能不足
- ❌ 纪元之间的差异主要是数值和解锁，缺乏玩法变化
- ❌ 节奏感设计不够——缺乏"一档之内的微操心流"
- ❌ 卡牌战术系统和操作系统的结合不够紧密，感觉像两个游戏拼接
- ❌ Boss设计停留在概念层面，缺乏具体的机制对抗设计

**V2改进方向：**
1. 重新设计单档进攻的操作——引入"时间窗口"和"阅读链"机制
2. 防守回合加入交互性
3. 强化纪元之间的玩法变化
4. 设计更紧密的"卡牌×操作"融合机制
