## 一、「战术工坊」——玩家自创路线系统

### 1.1 解锁条件
纪元3通关后解锁「战术工坊」。

### 1.2 创建流程

```
┌─ 战术工坊 ──────────────────────────────────┐
│                                               │
│  1. 选择阵型底板（几种预设站位）                │
│     · Shotgun / Trips / Empty / Bunch 等      │
│                                               │
│  2. 为每个接球手「画路线」                      │
│     · 手指/鼠标在场地上画出跑动路径             │
│     · 系统自动识别路线类型（Slant/Out/Post等）  │
│     · 也可以画出非标准路线（自由创作）          │
│                                               │
│  3. 设定阅读顺序                               │
│     · 拖拽接球手排列优先读序                    │
│                                               │
│  4. 设定克制/弱点标签                           │
│     · 系统根据你的路线组合自动推断              │
│     · 你也可以手动调整                          │
│                                               │
│  5. 命名 & 保存                                │
│     · 给你的战术起名                            │
│     · 保存到自定义Playbook                     │
│                                               │
│  6. 测试场                                     │
│     · 在训练场对各种防守测试你的战术             │
│     · 系统给出评分：实用性/创意/对特定防守效果   │
│                                               │
└───────────────────────────────────────────────┘
```

### 1.3 社区分享

```
玩家自创战术可以：
- 上传到「战术社区」
- 其他玩家评分、下载、使用
- 每周评选「最佳社区战术」→ 纳入官方卡池
- 被下载超过1000次的战术 = 创作者获得限定称号「战术设计师」

→ 这创造了UGC（用户生成内容）循环
→ 极大延长游戏寿命
→ 让真正懂橄榄球的玩家有表达空间
```

## 二、休赛期系统：「Off-Season」

### 2.1 触发时机
每个赛季通关（无论胜败）后，进入为期约15分钟的休赛期。

### 2.2 休赛期三大活动

```
═══════════════════════════════════════
🎓 活动1：选秀大会（Draft）— 5分钟
═══════════════════════════════════════

模拟真实选秀体验：

1. 系统生成12个候选队友（随机能力和性格）
2. 你有有限的「侦察点」可以用来了解候选人详情
   - 免费看：名字、位置、星级
   - 1点侦察：看具体属性
   - 2点侦察：看性格和被动技能
   - 3点侦察：看隐藏潜力值

3. 然后进行3轮选秀（你和AI对手交替选人）
   - 第1轮选秀权顺序取决于上赛季战绩（越差选越早）
   - → Roguelike的失败保护机制！输了也有好处！

4. 选秀策略：
   - 选确定的强力球员？还是赌一个未知但潜力高的新人？
   - 你的球队需要速度型外接手还是保护型中锋？
   - 某些球员之间有隐藏的羁绊关系（来自同一背景），选一对效果更好

═══════════════════════════════════════
🏋️ 活动2：训练营（Training Camp）— 5分钟
═══════════════════════════════════════

一系列提升属性的小游戏：

「传球靶场」
  - 移动的靶子，画线传球击中得分
  - 得分越高 → 精准度属性提升越多

「阅读闪卡」
  - 快速闪现防守阵型，你要在1秒内判断类型
  - 正确率越高 → 阅读力属性提升越多

「体能测试」
  - 简单的反应力/节奏小游戏
  - 表现越好 → 机动性和体力提升

「战术研习」
  - 给你一个战术卡的文字描述
  - 你要从4个路线图中选出正确的那个
  - 正确数越多 → 解锁更好的起始Deck

每个小游戏约1-2分钟，轻松愉快但有实际效果。

═══════════════════════════════════════
📰 活动3：休赛期事件（Off-Season Stories）— 5分钟
═══════════════════════════════════════

2-3个叙事事件，影响下赛季：

事件示例：

「媒体采访」
  记者问你："你觉得下赛季最大的挑战是什么？"
  A.「加强防守阅读」→ 下赛季阅读期+0.5秒
  B.「提升长传能力」→ 下赛季长传码数+10%
  C.「打造更好的团队」→ 下赛季队友初始羁绊+1级
  D.「我没什么好说的。」→ 获得「低调」buff：对手侦察信息更少

「老队友来信」
  如果上赛季有高羁绊的队友没被留下：
  "嘿队长，虽然我们不在一个队了，但我发现了一些东西..."
  → 获得一张上赛季队友推荐的战术卡
  → 小小的情感联系，让玩家感觉队友不只是数值

「神秘包裹」
  你收到一个匿名包裹，里面有一件装备/遗物
  "来自一个曾经伟大的四分卫。他说你会需要它。"
  → 随机获得一个遗物，品质取决于你名人堂中QB的数量
  → Meta进度的情感回馈
```

## 三、无障碍 & 包容性设计

### 3.1 色觉辅助

```
窗口颜色系统的色盲替代方案：

默认：🟢绿 / 🟡黄 / 🔴红
色盲模式A：形状替代 → ⭕空档 / △有风险 / ✕被覆盖
色盲模式B：图案替代 → 空心/斜线/实心填充
色盲模式C：自定义颜色选择器

所有颜色编码信息同时有：
- 颜色
- 形状/图案
- 动画效果（绿色=平稳、黄色=闪烁、红色=抖动）
- 音效（绿=清脆叮、黄=嗡嗡、红=低沉）
→ 多通道冗余信息确保无障碍
```

### 3.2 单手模式

```
考虑到通勤等场景，提供单手操作模式：

- 所有操作集中在屏幕右半部分（可切换左半部分）
- 传球从"画线"简化为"方向滑动"
- 战术选择用上下滑动替代拖拽
- 菜单交互用长按替代双击
```

### 3.3 难度无限可调

```
除了"教练辅助面板"的开关，还提供：

- 文字大小调节
- 游戏速度调节（0.5x ~ 2.0x）
- 自动暂停选项（每档之间自动暂停，按任意键继续）
- 教程可随时重看
- 关键概念解释可在任何战术卡上长按查看
```

## 五、最终设计摘要——电梯演讲版

> **《Pocket Commander》是什么？**
>
> 一款将Roguelike的随机性和重玩性、卡牌构筑的策略深度、
> 节奏游戏的操作快感、RPG的角色养成和叙事情感，
> 融合进腰旗橄榄球的框架中的游戏。
>
> **核心创新：**
> - 「弹道绘制」：用画线的方式传球——直觉、有深度、独一无二
> - 「阅读序列」：把真实QB的防守阅读变成紧张刺激的决策游戏
> - 「兄弟连」：你的队友不是工具，是有故事的伙伴
> - 「失败叙事」：输了也是故事的一部分，让你想立刻再来一局
>
> **玩家能学到什么？**
> 在不知不觉中掌握：防守阵型识别、进攻战术选择、
> 阅读顺序、变阵时机、战术多样性——真正的四分卫思维。
>
> **够玩多久？**
> 首次通关约20小时，完整体验40小时+，含PVP和无限模式80小时+。
