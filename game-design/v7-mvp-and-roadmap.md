# 🏈 《Pocket Commander》— V7 MVP定义 & 开发路线图
## 核心主题：减法设计——用最少的系统交付最完整的核心体验

---

## V6 回顾：97分，但有个关键问题

V6设计了一个"梦想级"游戏，但系统总量已经庞大到不现实：
- 5个纪元 × 每纪元独特美术
- 程序化叙事引擎
- 弹道绘制传球
- 侦察度 + 进攻哲学 + 对手记忆
- 战术工坊 + 社区分享
- 幽灵对战PVP
- Football IQ系统
- 动态解说系统
- ...

如果同时做所有东西 = 永远做不完。

**V7的任务：把V1-V6的所有设计分层，定义什么必须做、什么可以后加、什么可以砍掉。**

## 一、MVP定义原则

```
MVP必须满足：
1. 核心Game Loop完整且有趣（能让玩家玩进去）
2. 教学目标达成（玩完MVP能识别基础防守并做阅读）
3. 有足够内容支撑至少6-8小时的游戏体验
4. 有Roguelike的核心循环（死亡→成长→再战）
5. 技术实现可行（3-6个月可完成原型）

MVP可以没有：
- 完整的5个纪元（只做纪元1-2）
- PVP系统
- 程序化叙事引擎（用预设事件代替）
- 战术工坊
- 动态解说
- 每个纪元独特美术（统一风格）
```

## 二、系统优先级分层

### Tier 0：核心中的核心（MVP Day 1）

```
这些系统如果不存在，游戏就不是这个游戏：

1. 「阅读序列」系统
   - 窗口颜色（绿/黄/红）
   - 口袋压力条
   - 2-3个接球手可选
   → 这是整个游戏的教学灵魂

2. 「弹道绘制」传球
   - 直线/弧线/高抛 三种基本划法
   - 简化版（点击目标自动传球）作为辅助
   → 如果弹道绘制原型验证手感不好，备案：
     改为"方向+蓄力"的传统方案（但降低独特性）

3. 基础战术卡系统
   - 10-15张基础战术卡
   - Deck构建（8张Deck，MVP减小规模）
   - 卡牌不需要升级/稀有度（MVP简化为白/绿两级）

4. 基础防守回合
   - 选择防守战术（4种：Man/Cover 2/Cover 3/Blitz）
   - 「猜意图」QTE（跑/短传/长传）
   - 拔旗QTE

5. 单场比赛完整流程
   - 进攻/防守轮替
   - 分数系统
   - 比赛结算
```

### Tier 1：核心体验完整（MVP必须有，但可简化）

```
6. 赛季结构
   - 简化版：5场常规赛 + 1场Boss（共6场/赛季）

   - 1个赛季修饰符（随机）

   - 3个教学关（传球/选目标/完整比赛）

10. 教练辅助面板

11. 侦察度系统（简化版）

    - 不需要百分比精确值
```

## 三、MVP详细设计（去掉所有冗余后的精华）

### 3.1 MVP游戏流程

```
新手教程（15分钟）
  → 3个教学关
  → 开场漫画（可跳过）

↓

赛季1（纪元1·街头·3v3）
  → 选择起始Deck（3个预设Deck选1）
  → 5场常规赛 + 1场Boss
  → 每场约15分钟
  → 赛季总时长：约2小时

↓

赛季失败 → 保留：解锁的战术知识
          → 失去：赛季Deck和比赛币
          → 获得：永久属性点
          → 重新开始新赛季

赛季胜利 → 解锁纪元2预告
          → 解锁更多起始Deck选项
          → 获得更多永久属性点

↓

重复赛季直到纪元1通关
（预计2-4个赛季，4-8小时）
```

### 3.2 MVP战术卡表

```
MVP只需要12张战术卡：

短传（4张）：
  · Slant — 斜切内线，克Cover 3/Zone
  · Out Route — 外切边线，克Man
  · Curl — 跑出转身，安全选择
  · Screen Pass — 短传给前方，克Blitz

中传（4张）：
  · Dig/In — 内切中路，克Cover 2
  · Corner — 外切深区，克Cover 3
  · Post — 斜切深中，克Cover 2
  · Drag — 横穿底线，万能选择

长传（2张）：
  · Go/Fly — 直线冲刺，克单人盯防
  · Deep Cross — 深度交叉，克Zone

特殊（2张）：
  · QB Draw — 四分卫跑动，克松散防守
  · Play Action — 假跑真传，克激进防守

每张卡包含：
  - 名字
  - 路线图示
  - 1句阅读提示
  - 克制标签（克什么防守）
  - 弱点标签（被什么防守克）
```

### 3.3 MVP防守系统

```
4种可选防守：

Man-to-Man（盯人）
  → 每个防守人贴身盯一个接球手
  → 克制：短传Screen
  → 弱于：Go Route / Pick Play

Cover 2（双安全卫区域）
  → 两个安全卫分守深区两侧
  → 克制：边路深传
  → 弱于：中路深传（Post/Dig）

Cover 3（三人深区）
  → 三人分守深区
  → 克制：长传
  → 弱于：边路短传（Out/Flat）

Blitz（突袭）
  → 多人冲向QB
  → 克制：需要长时间的路线
  → 弱于：Screen / Quick Pass

防守回合操作：
  1. 选择4种防守之一
  2. Snap后1.5秒内猜「跑/短传/长传」
  3. 如果对手传球到你的区域 → 拔旗QTE
```

### 3.4 MVP Boss：「铁壁教练」

```
纪元1唯一Boss（简化版）：

机制：
  · 每3档切换防守体系（Man→Cover2→Cover3→Blitz→循环）
  · 防守球员不犯错
  · 被你得分后"暴怒"→ 全Blitz 2档

胜利条件：赢得比赛

教学验证：
  · 如果玩家能赢这个Boss = 证明已掌握基础防守识别和对策
```

## 四、技术架构建议

### 4.1 推荐引擎

```
首选：Unity（2D模式）
理由：
  - 成熟的2D工具链
  - 弹道绘制的触摸输入处理方便
  - 多平台发布（iOS/Android/PC）
  - 卡牌游戏框架丰富

备选：Godot 4
理由：
  - 免费开源
  - GDScript上手快
  - 适合小团队快速原型
```

### 4.2 关键技术挑战

```
1. 弹道绘制输入系统
   - 需要识别划线形状（直线/弧线/高抛）
   - 计算划线速度和方向
   - 技术方案：采样点 → 曲线拟合 → 分类
   - 估计开发时间：2-3周

2. 战术执行模拟
   - 接球手路线跑位（预定义路线的插值动画）
   - 防守人覆盖计算（基于站位和速度的简单模型）
   - 传球飞行物理（简化的抛物线/直线）
   - 估计开发时间：3-4周

3. 窗口颜色动态计算
   - 实时计算接球手与最近防守人的距离
   - 考虑防守人的移动方向和速度
   - 映射为绿/黄/红三色
   - 估计开发时间：1-2周

4. 对手AI
   - MVP只需要基础AI：根据所选防守执行覆盖
   - 不需要学习型AI（那是Tier 3）
   - 估计开发时间：2-3周
```

### 4.3 MVP开发时间线（估算）

```
假设：2-3人核心团队

第1个月：核心原型
  · 弹道绘制输入
  · 单档进攻的完整流程
  · 基础窗口颜色系统
  → 里程碑：一个能玩的"单档进攻"原型

第2个月：比赛系统
  · 防守回合
  · 完整比赛流程（进攻/防守轮替）
  · 比赛结算
  → 里程碑：一场完整的比赛可以打完

第3个月：赛季和养成
  · 赛季结构（5场+Boss）
  · 商店系统
  · QB属性成长
  · 侦察度（简化版）
  → 里程碑：一个完整赛季可以打完

第4个月：教学和打磨
  · 新手教程
  · 教练辅助面板
  · Boss设计和实现
  · 数值平衡
  → 里程碑：MVP可发布Alpha版

第5个月：美术和音频
  · 统一的纪元1美术风格
  · 基础音效
  · UI打磨
  → 里程碑：MVP可发布Beta版

第6个月：测试和优化
  · 玩家测试
  · Bug修复
  · 数值调整
  · 性能优化
  → 里程碑：MVP 1.0发布
```

## 六、商业化设计（无P2W原则）

```
核心原则：绝不Pay-to-Win

可接受的变现方式：

1. 买断制（推荐）
   - MVP免费（纪元1）
   - 纪元2-5作为付费DLC或一次性买断解锁
   - 价格：$6.99 全解锁

2. 外观商城（如果走F2P路线）
   - QB自定义外观（发型/球衣颜色/庆祝动作）
   - 战术卡皮肤（不影响效果，只是不同的路线图视觉风格）
   - 表情包
   - 限定称号框

3. 赛季通行证（可选，如果有长期运营计划）
   - 免费轨道：基础奖励
   - 付费轨道：额外外观+加速获取（不是Pay-to-Win）
   - 每月更新内容

绝不出售：
   ✕ 战术卡（不卖power）
   ✕ 属性提升
   ✕ 体力/次数限制（没有体力系统）
   ✕ 跳过内容的捷径
```

## V7 自我评审

### 评分：97/100（持平）

**V7的价值不在于提升设计分数，而在于让V1-V6的设计变得"可执行"：**

- ✅ 清晰的4层优先级（Tier 0-3），团队知道先做什么
- ✅ MVP精确到12张战术卡、4种防守、1个Boss——极其聚焦
- ✅ 6个月MVP时间线现实可行（2-3人团队）
- ✅ 后续版本路线图有节奏感，每个版本有明确的主题
- ✅ 技术架构建议实际且不过度设计
- ✅ 商业化设计尊重玩家，不搞P2W
- ✅ MVP去掉了所有"Nice to have"，只保留了让游戏能跑起来的最小集合
- ✅ 但侦察度这个核心博弈保留在了MVP中（因为它是灵魂）

**这不是一个新设计，而是一个"怎么把前6个版本的设计变成现实"的执行方案。**
